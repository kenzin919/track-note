# 陸メモ GitHub版

GitHub Pagesで公開するスマホ向け陸上記録アプリです。

- 大会結果
- PB自動判定
- 記録推移
- プロフィール・アイコン
- グループ
- 招待コード
- グループメンバー
- グループ内チャット（この端末のブラウザ保存）

## GitHubへの公開

ZIPを展開し、中のファイルをGitHubリポジトリ直下へアップロードしてください。

## 注意

GitHub Pagesだけでは、複数のスマホ間でデータをリアルタイム共有するためのデータベース機能はありません。
そのため、この版のグループ・チャットはブラウザ内保存です。

将来、本当に友達の端末と共有する場合は、別途データ保存サービスが必要になります。
