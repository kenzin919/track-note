# Track Note 公開版

スマホで使えるPWA対応のWebアプリです。

## 今回の公開版
- ホーム
- 練習記録
- 大会結果
- PB自動判定
- 記録推移グラフ
- プロフィール名・写真
- グループUI
- スマホのホーム画面へのインストール（PWA）
- オフラインキャッシュ
- レスポンシブUI

## 無料公開
GitHub Pages / Cloudflare Pagesなどの静的ホスティングに、このフォルダの中身をアップロードすれば公開できます。
`index.html` が入口です。

## 注意
現在のデータはブラウザのlocalStorageに保存されます。
そのため、この公開版だけでは複数ユーザー間のクラウド同期はまだ行いません。
グループを本当の複数端末共有にする次の工程では、認証・データベース・画像ストレージを接続します。

## 推奨URL
独自ドメインを使わない場合は、ホスティングサービスの無料サブドメインで開始できます。
